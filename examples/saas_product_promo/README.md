# SaaS Product Promo Example (16:9 Landscape)

This reference composition demonstrates a high-converting 15-second promo video for a software product.

## Specifications
- **Aspect Ratio**: `16:9` (1920x1080)
- **Frame Rate**: `30 FPS`
- **Total Duration**: `15.0 seconds` (450 frames)
- **Visual Aesthetic**: Modern Dark SaaS (`#090D16` Obsidian Navy, Indigo/Sky Blue accents, Glassmorphism)

## Scene Breakdown
1. **Scene 1: Hook (0s - 3s / frames 0 - 89)**: Kinetic split-text asking a provocative question with background radial glow.
2. **Scene 2: Solution Reveal (3s - 8s / frames 90 - 239)**: 2.5D camera zoom and tilt on a browser mockup featuring a live dashboard.
3. **Scene 3: Impact Metric (8s - 12s / frames 240 - 359)**: Animated number ticker counting to "10x Faster".
4. **Scene 4: Outro CTA (12s - 15s / frames 360 - 449)**: Animated brand badge and call-to-action button.
